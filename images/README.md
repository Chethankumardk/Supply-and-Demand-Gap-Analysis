# Power BI Visuals

This folder contains selected visuals from the Uber Supply & Demand Gap Analysis.

## Main Dashboard

`uber_supply_demand_dashboard.png`

Provides an overview of:
- total ride requests
- pickup-point distribution
- request status
- completed trips
- cancelled requests
- requests with no cars available
- overall supply versus no-supply

The analyzed dataset contains 6,745 ride requests. The dashboard shows approximately 41.97% Supply and 58.03% No-Supply.

## Time-Period Analysis

`uber_time_period_analysis.png`

Provides a more detailed comparison of:
- request volume by time period
- request status by time period
- City versus Airport demand
- pickup point and request-status patterns

The project analysis identifies Morning City demand and Evening Airport demand as important periods for understanding the supply-demand gap.

These images are included to provide a quick visual summary of the Power BI analysis without requiring the `.pbix` file to be opened.
