# Power BI Project

This folder contains the editable Power BI project used for the Uber Supply & Demand Gap Analysis.

## File

` supply_demand_gap_analysis.pbix `

The Power BI project was used to:

- analyze ride requests by pickup point
- compare Trip Completed, Cancelled, and No Cars Available statuses
- analyze request patterns across different time periods
- classify requests into Supply and No-Supply
- visualize City and Airport demand patterns
- build the final analysis dashboard

## Main Analysis Areas

The dashboard focuses on:

- total ride-request volume
- request-status distribution
- City vs Airport pickup patterns
- supply-demand gap
- Morning, Afternoon, Evening, and Night patterns
- periods associated with cancellations and car unavailability

## Portfolio Preview

Static dashboard previews are available in the repository's `images/` folder so that the main results can be reviewed without opening Power BI Desktop.
