# Project Documentation

This folder contains supporting documentation for the Uber Supply & Demand Gap Analysis.

## Project Report

` supply_demand_gap_analysis_report.pdf `

The report documents:

- project objective
- analysis methodology
- dataset fields
- data preprocessing
- derived analysis fields
- Power BI dashboard
- request-status analysis
- City and Airport comparison
- time-period analysis
- key findings
- recommendations

## Main Findings Documented in the Report

The analysis identifies two important supply-demand patterns:

- **Morning City:** high demand accompanied by a high level of cancellations
- **Evening Airport:** high demand accompanied by a high level of requests where no cars were available

The report recommends improving driver availability and considering driver incentives during high-demand periods.
